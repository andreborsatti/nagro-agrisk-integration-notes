# nagro-agrisk-integration-notes

Notas internas de integração entre a plataforma **Nagro** e o motor de
qualificação de risco da **AgRisk Technologies**.

## Contexto

O Grupo Nagro Co. opera a Nagro SCD (Sociedade de Crédito Direto) voltada ao
agronegócio brasileiro. A esteira de crédito consome scores produzidos pela
AgRisk e os resultados são consolidados no SGC.

Domínios envolvidos:

- https://nagro.co
- https://www.nagro.co
- https://nagro.com.br
- https://agrisk.com.br
- https://agrisk.app
- https://agrisk.dev
